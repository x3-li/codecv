# 如何使用 AI 生成网页版 PPT

这是一份面向公司内部技术分享的 HTML 版演示稿，主题是“如何使用 AI 生成网页版 PPT”，演讲时间约 15 分钟。

## 文件结构

- `index.html`：演示稿内容
- `style.css`：日系简约视觉样式与打印样式
- `script.js`：翻页、页码、进度条、全屏与打印控制

## 使用方式

直接用 Chrome、Edge 或 Safari 打开 `index.html`。

操作：

- `←` / `→`：上一页 / 下一页
- `PageUp` / `PageDown`：上一页 / 下一页
- `Home` / `End`：第一页 / 最后一页
- `F`：切换全屏
- `PDF` 按钮：调用浏览器打印，可另存为 PDF
