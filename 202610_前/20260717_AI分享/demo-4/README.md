# AIツールでWeb版PPTを作る方法

生産技術部-AI活用向けのHTML版PPTです。テーマは「AIツールを使って、PromptからWeb版PPTをすばやく生成する方法」です。

## ファイル構成

```text
demo-4/
  index.html
  style.css
  script.js
  README.md
```

## 使い方

1. `index.html` をブラウザで開きます。
2. 画面右下の `‹` / `›` ボタン、またはキーボードの左右キーでスライドを移動します。
3. `⛶` ボタン、または `F` キーで全画面表示に切り替えます。
4. `PDF` ボタン、または `P` キーで印刷画面を開き、PDFとして保存します。

## 操作

- 次へ: 右矢印、PageDown、Space
- 前へ: 左矢印、PageUp、Backspace
- 最初へ: Home
- 最後へ: End
- 全画面: F
- 印刷: P または PDFボタン
