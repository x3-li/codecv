# UI 层设计

按照下面的流程显示在UI层，使用chainlit模块显示。
```
user： 帮我做成一个dashboard
AI thinkings : 好， 我来查看调用tool
Tool message： 调用create_dashboard tool 。 arg xxx
cl.step1: 正在创建confluence page
cl.step2: 正在赋予权限
cl.step3: 正在编辑page
cl.step3: 正在检查page
AI： dashboard做完了，url:xxxx。
```

# agent tool
```
@tool
def create_dashboard():
   return dashboard.run()
   
```
dashboard.run() 中的各个step method都是使用cl.step标记的。
