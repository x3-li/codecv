ローカルLLM（vLLM + LiteLLM）検証用テストケース
1. テスト目的

本テストは、ローカル環境に構築した大規模言語モデル（LLM）が
vLLM + LiteLLM 経由で提供される際の品質および実用性を検証することを目的とする。

主な確認観点は以下の通り：

基本的な対話能力
日本語対応能力
指示理解能力
コード生成・修正能力
Claude Code 連携時の実用性
2. 前提条件
vLLM サーバーが正常に起動していること
LiteLLM を経由して OpenAI 互換 API が利用可能であること
Claude Code CLI が LiteLLM に接続済みであること
モデルの chat template / tokenizer 設定が正常であること
3. テストケース一覧
① 基本チャットテスト
■ TC-01：基本挨拶

目的
モデルの基本応答可否を確認する

入力

hello

期待結果

正常な挨拶文が返却される
エラー・タイムアウトが発生しない
不自然な長文出力がない

判定基準

1～5文程度の自然な応答
応答時間が許容範囲内
■ TC-02：コンテキスト保持

目的
会話の文脈保持能力を確認する

入力

2回目：

私の名前は何ですか？

期待結果

「Tom」と正しく回答する

判定基準

文脈を正しく保持できている
■ TC-03：中英混在理解

実用性	開発への適用可能性	0～5
5. 総括テンプレート
本検証では、ローカルLLM（vLLM + LiteLLM）について、
基本対話、日本語処理、および Claude Code 連携時の能力を評価した。

結果として、
・基本対話および簡易タスクは概ね問題なく実行可能
・日本語処理は一定水準に達しているが、複雑な表現にはばらつきあり
・コード関連タスクはモデル依存で品質差が大きい

今後は、実プロジェクトでの適用可否を判断するため、
長文処理、ツール連携、実コード修正精度の追加検証が必要である。
